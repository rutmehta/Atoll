# boring.notch (TheBoredTeam) — Implementation Architecture

MIT-adjacent open-source NotchNook alternative (GPL-3.0), Swift/SwiftUI, macOS 14+, builds with Xcode 26. Single Xcode project `boringNotch.xcodeproj` plus an XPC service target `BoringNotchXPCHelper` and a vendored `mediaremote-adapter/` directory (perl script + prebuilt MediaRemoteAdapter.framework + MediaRemoteAdapterTestClient).

## 1. Notch window creation

**Class**: `BoringNotchSkyLightWindow: NSPanel` (current; older `BoringNotchWindow: NSPanel` still in tree). Created in `AppDelegate.createBoringNotchWindow(for:with:)` in `boringNotchApp.swift`:
- `styleMask: [.borderless, .nonactivatingPanel, .utilityWindow, .hudWindow]`, `backing: .buffered`
- Config: `isFloatingPanel=true`, `isOpaque=false`, `backgroundColor=.clear`, `hasShadow=false`, `isMovable=false`, `titleVisibility=.hidden`, `titlebarAppearsTransparent=true`, `isReleasedWhenClosed=false`, forced `appearance = NSAppearance(named: .darkAqua)`
- **Window level**: `level = .mainMenu + 3`
- **collectionBehavior**: `[.fullScreenAuxiliary, .stationary, .canJoinAllSpaces, .ignoresCycle]` — fullScreenAuxiliary makes it visible over fullscreen apps
- `canBecomeKey`/`canBecomeMain` overridden to `false`; shown with `orderFrontRegardless()`
- `sharingType = .none` when `Defaults[.hideFromScreenRecording]` (hides from screen capture)
- Content is one `NSHostingView(rootView: ContentView().environmentObject(viewModel))`

**Above-fullscreen reinforcement via private CGS Spaces API** (`private/CGSSpace.swift`, from avaidyam/Parrot): `@_silgen_name` bindings to `_CGSDefaultConnection`, `CGSSpaceCreate` (flag MUST be 1 or Finder redraws desktop icons), `CGSSpaceSetAbsoluteLevel`, `CGSShowSpaces`, `CGSAddWindowsToSpaces`, `CGSRemoveWindowsFromSpaces`. `NotchSpaceManager.shared.notchSpace = CGSSpace(level: 2147483647)` and every notch window is inserted into that space (`notchSpace.windows.insert(window)`).

**Lock-screen visibility**: SPM package `Lakr233/SkyLightWindow` — `SkyLightOperator.shared.delegateWindow(window)` on `com.apple.screenIsLocked` (DistributedNotificationCenter), undelegate 150 ms after `com.apple.screenIsUnlocked` via dlopen'd `SLSRemoveWindowsFromSpaces` from SkyLight.framework.

**Positioning** (`positionWindow`): window frame is always the OPEN size (`windowSize = 640 × (190+20 shadowPadding)`), pinned top-center: `x = screenFrame.origin.x + screenFrame.width/2 - window.frame.width/2`, `y = screenFrame.origin.y + screenFrame.height - window.frame.height`. No frame animation ever — all morphing is SwiftUI-internal.

**Notch measurement** (`sizing/matters.swift`, `getClosedNotchSize(screenUUID:)`): width = `screen.frame.width - auxiliaryTopLeftArea.width - auxiliaryTopRightArea.width + 4` (fallback 185 pt for non-notch displays). Notch presence detected by `screen.safeAreaInsets.top > 0`. Height modes: `.matchRealNotchSize` = `safeAreaInsets.top`, `.matchMenuBar` = `frame.maxY - visibleFrame.maxY`, or user-set `Defaults[.notchHeight]`/`.nonNotchHeight`.

**Multi-display**: `windows: [String: NSWindow]` and `viewModels: [String: BoringViewModel]` keyed by display UUID (`NSScreen+UUID.swift` extension `displayUUID`); rebuilt on `NSApplication.didChangeScreenParametersNotification` comparing UUID sets and frames.

## 2. Hover / expand animation

All in `ContentView.swift` + `NotchShape.swift`:
- `NotchShape: Shape` (derived from MrKai77/DynamicNotchKit): path drawn with `addQuadCurve` — outward-curving top corners and rounded bottom corners; `animatableData: AnimatablePair<CGFloat, CGFloat>` (topCornerRadius, bottomCornerRadius) so the shape morphs smoothly. Radii: closed (top 6, bottom 14) → opened (top 19, bottom 24) (`cornerRadiusInsets` constant).
- Layout: `NotchLayout()` VStack `.background(.black).clipShape(currentNotchShape)` with a 1-pt black Rectangle overlay at top to seal against the physical notch. Open state sets `.frame(height: vm.notchSize.height)` where `vm.open()` assigns `notchSize = openNotchSize` (640×190); close reassigns `getClosedNotchSize()`. State enum `NotchState .closed/.open` on `BoringViewModel`.
- Springs: open `Animation.spring(response: 0.42, dampingFraction: 0.8)`, close `spring(response: 0.45, dampingFraction: 1.0)`, hover/gesture `interactiveSpring(response: 0.38, dampingFraction: 0.8)`, applied via `.animation(_, value: vm.notchState)`.
- Hover: `.onHover` → `hoverTask = Task { try await Task.sleep(for: .seconds(Defaults[.minimumHoverDuration])); … vm.open() }` (cancelable debounce); un-hover has a 100 ms debounce before `vm.close()`. Haptics: `.sensoryFeedback(.alignment, trigger: haptics)`.
- Open-content transition: `.transition(.scale(scale: 0.8, anchor: .top).combined(with: .opacity).animation(.smooth(duration: 0.35)))`; album art shared between closed live activity and open player via `matchedGeometryEffect(id: "albumArt", in: albumArtNamespace)`.
- Gestures: custom `PanGesture` extension (NSEvent scroll/pan phases); `gestureProgress = (translation / Defaults[.gestureSensitivity]) * 20` drives a subtle `scaleEffect` and width growth, opening/closing when threshold crossed.
- Fullscreen hiding: `FullscreenMediaDetector` consumes `MacroVisionKit.FullScreenMonitor.shared.spaceChanges()` async stream → `fullscreenStatus: [screenUUID: Bool]` → `BoringViewModel.hideOnClosed` → `effectiveClosedNotchHeight = 0` collapses the closed notch. `.nowPlayingOnly` mode only hides when the fullscreen space runs the media app's bundle ID.

## 3. Now-playing via mediaremote-adapter (macOS 15.4+ workaround)

Since macOS 15.4 `MRMediaRemoteGetNowPlayingInfo`/observers require a private entitlement. boring.notch vendors **ungive/mediaremote-adapter** (BSD-3):
- **The trick**: mediaremoted grants MediaRemote access to processes whose bundle ID starts with `com.apple.`; `/usr/bin/perl` is reported as `com.apple.perl5`. The perl script `mediaremote-adapter.pl` uses `DynaLoader::dl_load_file` to load the bundled (NOT linked) `MediaRemoteAdapter.framework`, then `dl_find_symbol`/`dl_install_xsub` to invoke exported C functions: `adapter_stream`, `adapter_get`, `adapter_send`, `adapter_seek`, `adapter_shuffle`, `adapter_repeat`, `adapter_speed`, `adapter_test`. Parameters pass via env vars (`MEDIAREMOTEADAPTER_PARAM_<func>_<i>_<name>`, `MEDIAREMOTEADAPTER_OPTION_<name>`; options: `--no-diff`, `--debounce=N`, `--micros`, `--now`).
- **Streaming**: `NowPlayingController.setupNowPlayingObserver()` runs `Process(executableURL: /usr/bin/perl, arguments: [script, Bundle.main.privateFrameworksPath + "/MediaRemoteAdapter.framework", "stream"])`, stdout → `Pipe` → actor `JSONLinesPipeHandler` (readabilityHandler + continuation, newline-delimited JSON) → `Codable NowPlayingUpdate { payload, diff }` → merged into `PlaybackState` (diff mode carries forward previous fields). Artwork arrives base64 in `artworkData`. `timestamp` (ISO8601) + `playbackRate` enable client-side elapsed-time extrapolation: `estimatedPlaybackPosition = elapsedTime + (now − timestampDate) × playbackRate` (no polling).
- **Deprecation probe**: `MediaChecker.checkDeprecationStatus()` runs `perl mediaremote-adapter.pl <framework> <testClient> test` with 10 s timeout; exit status 1 ⇒ NowPlaying unusable ⇒ `MusicManager` falls back to AppleScript `AppleMusicController` and shows an onboarding permissions step.
- **Commands are still sent in-process** (only observation was locked down): `CFBundleCreate` of `/System/Library/PrivateFrameworks/MediaRemote.framework` + `CFBundleGetFunctionPointerForName` + `unsafeBitCast` for `MRMediaRemoteSendCommand` (0=play, 1=pause, 2=togglePlayPause, 4=next, 5=previous), `MRMediaRemoteSetElapsedTime(Double)`, `MRMediaRemoteSetShuffleMode` (1=off,3=on), `MRMediaRemoteSetRepeatMode`.
- **Controller abstraction**: `MediaControllerProtocol` (playbackStatePublisher: `AnyPublisher<PlaybackState, Never>`, play/pause/togglePlay/nextTrack/previousTrack/seek/toggleShuffle/toggleRepeat/setVolume/setFavorite/updatePlaybackInfo/isActive, supportsVolumeControl, supportsFavorite). Implementations: `NowPlayingController` (MediaRemote), `AppleMusicController` & `SpotifyController` (AppleScript via `AppleScriptHelper`), `YouTubeMusicController` (REST to th-ch/youtube-music companion server with auth). `MusicManager` (singleton ObservableObject) subscribes to the active controller, diffs state, computes average artwork color (`avgColor`) for tinting/visualizer, falls back to app icon for artwork, fetches lyrics from LRCLIB (`lrclib.net/api/search`) with LRC timestamp parsing + binary search for the current line. Per-app volume via AppleScript `set sound volume`.

## 4. File shelf / tray drag-drop

- **Drop-in**: SwiftUI `.onDrop(of: [.fileURL, .url, .utf8PlainText, .plainText, .data], isTargeted:)` in three places: shelf panel (`ShelfView`), whole open notch (`GeneralDropTargetDelegate: DropDelegate` returning `DropProposal(operation: .cancel)` so it only tracks targeting), and a transparent full-window `dragDetector` overlay while closed. Three targeting `@Published` bools combined with `Publishers.CombineLatest3` into `anyDropZoneTargeting`; when targeted while closed → `coordinator.currentView = .shelf; vm.open()`; un-target debounced 500 ms then close unless a drop happened (`vm.dropEvent`).
- **Global drag detection before cursor reaches the window**: `DragDetector` (observers/DragDetector.swift) — `NSEvent.addGlobalMonitorForEvents` for `.leftMouseDown/.leftMouseDragged/.leftMouseUp`, detects a live content drag by observing `NSPasteboard(name: .drag).changeCount` change after mouseDown and validating types (`.fileURL`, `UTType.url`, `.string`); geometric hit-test against a notch-region rect at top-center of each screen → auto-open shelf. One detector per display.
- **Ingestion**: `ShelfDropService.items(from: [NSItemProvider])` async chain: `extractFileURL()` → `extractURL()` (link vs file) → `extractText()` → `loadData()` (writes temp file via `TemporaryFileStorageService`) → `extractItem()`; files stored as **security-scoped bookmarks** (`Bookmark` model), items typed `ShelfItem.kind = .file(bookmark:)/.link(url:)/.text(string:)`, persisted by `ShelfPersistenceService`, deduped by `identityKey`, stale bookmarks auto-refreshed.
- **Drag-out**: `DraggableClickHandler: NSViewRepresentable` wrapping `DraggableClickView: NSView, NSDraggingSource`; 3-pt drag threshold then `beginDraggingSession(with: [NSDraggingItem(pasteboardWriter: NSPasteboardItem)])` writing `.fileURL` + `.string`; `startAccessingSecurityScopedResource()` held for the drag duration; drag preview rendered from SwiftUI via `ImageRenderer(content:).nsImage`; `sourceOperationMaskFor .outsideApplication → [.copy, .move]`; optional auto-remove after successful drag. Multi-select drags via `ShelfSelectionModel`.
- **Extras**: AirDrop/share via `NSSharingService`/`NSSharingServicePicker.perform(withItems:)` (`QuickShareService`, `FileShareView`), Quick Look previews (`QuickLookService`), thumbnails via `ThumbnailService` (QuickLookThumbnailing).

## 5. HUD replacement (volume/brightness/backlight)

**No OSDUIHelper hack** — grep confirms zero OSDUIHelper/OSDManager references. Suppression works by **swallowing the media keys before macOS sees them**: `MediaKeyInterceptor` creates a `CGEvent.tapCreate(tap: .cghidEventTap, place: .headInsertEventTap, options: .defaultTap, eventsOfInterest: 1 << 14)` (CGEventType 14 = NSSystemDefined), converts to NSEvent, filters `subtype == 8`, decodes `keyCode = (data1 & 0xFFFF0000) >> 16` and key-down state `(data1 & 0xFF00) >> 8 == 0xA`. NX key codes: soundUp=0, soundDown=1, brightnessUp=2, brightnessDown=3, mute=7, kbBrightnessUp=21, kbBrightnessDown=22. Handled events **return nil** from the tap callback → the system OSD bezel never appears; the app then shows its own notch HUD. Steps are 1/16 (option+shift = 1/64 fine steps). Plays the system `volume.aiff` from `/System/Library/LoginPlugins/BezelServices.loginPlugin/.../Resources` when `com.apple.sound.beep.feedback == 1`. Requires Accessibility permission (event tap).
- **Volume**: `VolumeManager` uses CoreAudio directly — default device via `kAudioHardwarePropertyDefaultOutputDevice`, read/write `kAudioDevicePropertyVolumeScalar` (main element with per-channel 1–4 fallback, averaged), `kAudioDevicePropertyMute` with software-mute fallback, and `AudioObjectAddPropertyListenerBlock` on device/volume/mute so external volume changes also trigger the HUD (`lastChangeAt` + `shouldShowOverlay` 1.2 s window).
- **Display brightness** (in XPC helper to isolate private-API use): dlopen `/System/Library/PrivateFrameworks/DisplayServices.framework` → `DisplayServicesGetBrightness`/`DisplayServicesSetBrightness(CGDirectDisplayID, Float)`; fallback IOKit `IODisplayGetFloatParameter/IODisplaySetFloatParameter(kIODisplayBrightnessKey)` on a matched `IODisplayConnect` service.
- **Keyboard backlight**: private CoreBrightness.framework — `NSClassFromString("KeyboardBrightnessClient")`, method IMPs for `brightnessForKeyboard:`/`setBrightness:forKeyboard:` obtained via `class_getInstanceMethod` + `unsafeBitCast`, keyboardID 1.
- **XPC**: service `theboringteam.boringnotch.BoringNotchXPCHelper` (`BoringNotchXPCHelperProtocol`: isAccessibilityAuthorized, requestAccessibilityAuthorization, ensureAccessibilityAuthorization, keyboard/screen brightness get/set), consumed with ChimeHQ **AsyncXPCConnection** `RemoteXPCService`; accessibility status polled every 3 s, posts `.accessibilityAuthorizationChanged`.
- **HUD UI**: `BoringViewCoordinator.toggleSneakPeek(status:type:duration:value:icon:)` with `SneakContentType` (.volume/.brightness/.backlight/.mic/.music/.battery/.download), auto-hide task 1.5 s. Two styles: `InlineHUD` renders INSIDE the closed notch — icon+label left, a black spacer exactly `closedNotchSize.width - 20` wide bridging the physical notch, `DraggableProgressBar` right (drag writes back `VolumeManager.setAbsolute`/`BrightnessManager.setAbsolute`); or `SystemEventIndicatorModifier` (standard bar under the notch).

## 6. Battery live activity

- `BatteryActivityManager`: `IOPSNotificationCreateRunLoopSource` + `CFRunLoopAddSource`; snapshot via `IOPSCopyPowerSourcesInfo`/`IOPSCopyPowerSourcesList`/`IOPSGetPowerSourceDescription` (keys `kIOPSCurrentCapacityKey`, `kIOPSMaxCapacityKey`, `"Is Charging"`, `kIOPSPowerSourceStateKey == kIOPSACPowerValue`, `kIOPSTimeToFullChargeKey`); low-power mode via `NSProcessInfoPowerStateDidChange` + `ProcessInfo.processInfo.isLowPowerModeEnabled`. Diffs against previous `BatteryInfo` and emits typed `BatteryEvent`s through a serial queue (1 s spacing) to observers.
- `BatteryStatusViewModel` (singleton) maps events to `@Published` props + `statusText` ("Plugged In"/"Charging battery"/"Low Power: On"…) and calls `coordinator.toggleExpandingView(status: true, type: .battery)` on significant changes → the CLOSED notch widens to 640 pt (`computedChinWidth`) showing statusText left of the physical notch and `BoringBatteryView` (battery glyph with charging bolt) right; auto-collapses after 3 s. Clicking opens a popover menu (`BatteryMenuView`); `vm.isBatteryPopoverActive` blocks notch auto-close.

## 7. App structure

- `@main DynamicNotchApp: App` with `MenuBarExtra` + `@NSApplicationDelegateAdaptor(AppDelegate.self)`; Sparkle `SPUStandardUpdaterController` for updates. AppDelegate owns windows/viewModels dicts, screen-change observers, KeyboardShortcuts handlers (`.toggleSneakPeek`, `.toggleNotchOpen`), onboarding window, drag detectors.
- Singletons pattern throughout (`*.shared`): **managers/** MusicManager, VolumeManager, BrightnessManager+KeyboardBacklightManager, CalendarManager (EventKit), BatteryActivityManager, WebcamManager (AVCaptureSession mirror), NotchSpaceManager, ImageService; **models/** BoringViewModel (per-screen notch state machine), BatteryStatusViewModel, PlaybackState, SharingStateManager (preventNotchClose during share sheets); **coordinator** BoringViewCoordinator (@MainActor global UI state: currentView tabs .home/.shelf, sneakPeek, expandingView, screen selection with UUID migration); **observers/** DragDetector, FullscreenMediaDetector, MediaKeyInterceptor; **Shelf** MVVM (Models/Services/ViewModels/Views).
- SPM deps: sindresorhus/Defaults (settings), KeyboardShortcuts, LaunchAtLogin-Modern, airbnb/lottie-spm, TheBoredTeam/MacroVisionKit (fullscreen detection), EmergeTools/Pow (effects), Lakr233/SkyLightWindow (lock screen), Sparkle, swiftui-introspect, ChimeHQ/AsyncXPCConnection.
- Metal audio visualizer (`metal/visualizer.metal` + `AudioSpectrumView` masked gradient), Lottie animations, `Localizable.xcstrings` + Crowdin CI, DMG packaging via dmgbuild.
